# 📊 Sales Analysis Dashboard

An interactive Sales Analysis Dashboard built using Microsoft Excel to analyze sales performance, profitability, customers, products, regions, and geographic trends.

## 📌 Project Overview

This project transforms sales data into an interactive dashboard that provides a clear overview of business performance and helps identify important sales and profitability trends.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Filtering & Slicers

## 📊 Dashboard KPIs

- Total Sales: 2,297,201
- Return Sales: 180,504
- Net Sales: 2,116,697
- Net Profit: 263,165
- Total Customers: 793
- Total Orders: 5,009
- Average Profit: 28.7
- Profit per Customer: 361.16

## 📈 Analysis Included

- Sales by Region
- Sales by Category
- Top 10 Cities by Sales
- Top 10 States by Sales
- Sales & Quantity Trends by Year
- Sales by Sub-Category
- Sales by State & Category
- Customer-level analysis
- Returned vs. Non-returned orders

## 🎛️ Interactive Filters

The dashboard includes interactive filters for:

- City
- Order Year
- Category
- Person
- Returned Orders

## 💡 Key Insights

The dashboard provides insights into:

- Regional sales performance
- Top-performing cities and states
- Category and sub-category performance
- Yearly sales and quantity trends
- Customer performance
- Returned orders and their impact on sales
